# fumi

数式を含むMarkdownを、ターミナルでサッと読むための読み取り専用ビューアです（macOS・Linux向け）。

- Vimのキーバインドで移動・検索できます。
- コードのハイライトと、画面幅に合わせた表の描画に対応しています。
- 対応端末では、ブロック数式（`$$ ... $$`）を画像として表示します。
- 開いたファイルを書き換えることはありません。

## 動作環境

macOSとLinuxのターミナルで動作します。

数式を画像で表示するには、[Kitty Graphics Protocol](https://sw.kovidgoyal.net/kitty/graphics-protocol/)に対応したターミナル（kitty、Ghosttyなど）が必要です。対応していないターミナルでは数式がTeXのソースのまま表示されますが、ほかの機能はすべて使えます。tmux内でも、外側のターミナルが対応していれば数式を画像で表示できます。

## インストール

Rust 1.88以上とCargoが必要です。リポジトリのルートで次を実行します。

```sh
# PATHに入れて使う場合
cargo install --path . --locked
fumi README.md
```

```sh
# インストールせずにビルドだけする場合
cargo build --release --locked
./target/release/fumi README.md
```

## 使い方

```sh
fumi notes.md                             # 通常表示
fumi --plain notes.md                     # 画像を使わないテキスト表示
fumi --graphics off --color never notes.md  # 数式画像なし・色なし
fumi --help
```

| オプション | 値（太字が既定） | 説明 |
|---|---|---|
| `--plain` | — | 画像表示と端末の画像対応の確認を行わない、テキストだけの全画面表示。検索・色・表は使えます |
| `--graphics` | **`auto`** / `off` / `kitty` | 数式画像の表示方法。`--plain`を指定するとこちらより優先されます |
| `--color` | **`auto`** / `always` / `never` | 色の有無。`auto`では環境変数`NO_COLOR`（空でない値）に従います |

### キー操作

| 操作 | キー |
|---|---|
| 1行ずつ上下に移動 | `k` / `j`、↑ / ↓ |
| 半画面移動 | `Ctrl+u` / `Ctrl+d` |
| 1画面移動 | `Ctrl+b` / `Ctrl+f`、PageUp / PageDown |
| 先頭・末尾へ | `gg` / `G`、Home / End |
| 検索、次・前の一致へ | `/`、`n` / `N` |
| ヘルプ | `?` |
| 検索語・ハイライトの解除 | Esc |
| 終了 | `q` |

- マウスホイールでは3行ずつ移動します。
- 検索入力中のEsc / `Ctrl+c`は検索の取消、ヘルプ表示中のEsc / `?`は本文に戻る操作になります。`q`はヘルプ表示中もツールを終了します。

検索の細かい規則、対応ファイル、終了コードは[利用ガイド](docs/usage.md)を参照してください。

## 表示できるもの

- **Markdown**：見出し、強調、引用、リスト、タスク、コード、リンク、画像の代替テキスト。HTMLはタグも含めてそのまま文字として表示します。
- **日本語・絵文字**：結合文字や絵文字を含めて、見た目の幅を正しく数えて折り返します。
- **表**：画面幅に収まらない表は、1行ずつ縦に並べる形式に切り替えます。
- **数式**：ブロック数式は、内蔵の[RaTeX](https://github.com/erweixin/RaTeX)と同梱のKaTeXフォントで画像にします。外部のTeXは不要です。端末が画像に対応していない場合や変換に失敗した式は、TeXのソースをそのまま表示します。LaTeXとの完全な互換性はありません。

> **注意**：tmux内で数式画像を表示するとき、fumiは起動したペインの`allow-passthrough`を自動で`all`に設定します。**この設定はfumiを終了してもそのペインに残ります。** 条件と詳細は[数式・端末ガイド](docs/terminal-graphics.md#tmux)を参照してください。

### まだ対応していないもの

- Markdown中の画像の表示（代替テキストのみ表示）
- インライン数式（`$ ... $`）の画像化
- 標準入力からの読み込み
- ファイル変更時の自動再読み込み
- 見出しの拡大表示
