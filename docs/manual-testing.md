# 実端末チェックリスト

実際の端末で、表示・操作・終了後の復旧を確かめるための手順です。

- 自動テストの成功と、実端末での確認結果は分けて記録してください。
- MVPとv1の過去の結果は[MVP検証記録](verification.md)と[v1検証記録](v1-verification.md)にあります。下のチェック欄は、新しい環境で確認し直すためのものです。過去の報告があっても、個々の項目を確認済みとはみなしません。

## 準備

リポジトリのルートでビルドし、代表的なテスト用文書を開きます。

```sh
cargo build --release --locked
./target/release/fumi tests/fixtures/representative.md
```

まず普段使いの端末で確認し、その後Terminal.app・Ghostty・kittyなど、使える端末でも同じ操作を試してください。

次の情報を記録しておきます。

- OS・端末・フォントの名前とバージョン
- 画面サイズ
- tmux・SSHを使っているかどうか

## 基本の表示と操作

- [ ] **終了後の端末の復旧**：`q`、`Esc`、`Ctrl+c`のそれぞれで終了する（起動し直して1つずつ試す）。毎回元のシェル画面に戻り、カーソルが見え、文字入力・Enter・Backspaceが正常に使える。終了コードは順に0・0・130。
- [ ] **中断と再開**：本文を途中まで読み、`Ctrl+z`でシェルに戻る。`fg`で同じ位置に戻れる。中断中にウィンドウサイズを変えても、本文とステータスが崩れない。
- [ ] **日本語・絵文字の幅**：fixture冒頭の日本語、`é`、`が`、`👩‍💻`、`🇯🇵`、家族の絵文字を見る。重なり・欠け・行末での分断・ステータス行へのはみ出しがない。幅20・40・80・120セル付近で試す。
- [ ] **リサイズ時の位置保持**：手元の長いMarkdownも開き、段落の途中まで移動してからウィンドウ幅を広げたり狭めたりする。同じ箇所の付近を読み続けられ、先頭に飛ばない（末尾では、最後の行を収めるための位置調整が入るのは正常）。
- [ ] **最小サイズからの復帰**：幅20セル未満、または高さ4行未満に縮める。サイズ不足の表示になり、移動キーを押しても位置が変わらない。広げると元の位置に戻る。サイズ不足のままでも`q`・`Ctrl+c`で終了できる。
- [ ] **移動量と上下端**：`j`/`k`・↑↓、`Ctrl+d`/`u`、`Ctrl+f`/`b`・PageDown/Upを試す。移動の単位は折り返し後の表示行。`gg`・Homeで先頭、`G`・Endで末尾へ行き、末尾に余分な空白ページができない。位置表示は長い文書で先頭0%・末尾100%、1画面に収まる文書では100%。
- [ ] **ヘルプと`g`待ち**：本文の途中で`?`を押し、ヘルプ内を移動する。`q`・`Esc`・`?`で閉じると本文の位置が保たれ、次に開くとヘルプは先頭から表示される。通常画面で`g`→`Esc`は`g`の入力だけを取り消し、もう一度`Esc`で終了する。`g`→`j`は1行下に動く。
- [ ] **Markdownの内容**：見出し、引用、入れ子のリスト、9から始まる番号付きリスト、タスク、コードの空白・タブ、長い行の折り返し記号`↪`、リンク先、画像の代替テキストを確認する。表は画面幅に応じて表形式と縦形式が切り替わり、どちらでも全セルを読める。HTMLはタグごと文字として表示される。
- [ ] **数式のテキスト表示**：`--plain`で、`$x_i^2 + **literal**$`とブロック数式がTeXソースのまま読める。数式中の`**`などが装飾に変わらない。金額・エスケープ・コード内の`$`や、閉じられていない数式があっても、後に続く本文が消えない。
- [ ] **plainと色**：下のコマンドで表示を比べる。plainでも全画面で操作できる。色なしでも見出しとステータスを見分けられる。`NO_COLOR`を設定していても、`--color always`を明示すれば色が付く。
- [ ] **応答性**：普段使っている大きめの文書で、最初の表示、移動キーの連打、連続したリサイズで引っかかりがないか見る。初回と2回目以降を分けて記録する（初回起動200 msの目標は、これまでの測定では未達）。

色とplainの比較用コマンドです。1つずつ終了してから次を起動してください。

```sh
./target/release/fumi --plain tests/fixtures/representative.md
./target/release/fumi --color never tests/fixtures/representative.md
env NO_COLOR=1 ./target/release/fumi --color auto tests/fixtures/representative.md
env NO_COLOR=1 ./target/release/fumi --color always tests/fixtures/representative.md
```

検索、マウスホイール、数式の画像表示、コードのハイライトは、次の「v1の追加確認」で扱います（Markdown中の画像の表示は未実装です）。

## v1の追加確認

[手動確認用Markdown](examples/manual-debug.md)に、数式・検索・表・コードの確認例があります。リポジトリのルートから次のように開きます。結果はOS・端末・フォント・画面サイズと一緒に記録してください。

```sh
./target/release/fumi docs/examples/manual-debug.md
./target/release/fumi --plain --graphics kitty docs/examples/manual-debug.md
./target/release/fumi --graphics off docs/examples/manual-debug.md
./target/release/fumi --color never docs/examples/manual-debug.md
```

### 検索・マウス・コード・表

- [ ] **検索の基本**：`/hello world`、`/日本語`、`/frac`で、確定・0件・空入力での再検索・`n`/`N`の循環・反転と下線の強調を確認する。同じ行に複数ある一致も別々に数えられる。
- [ ] **検索の入力**：入力中の`q`は文字として入る。Esc/`Ctrl+c`で検索語・一致・位置が戻る。`Ctrl+u`の全消去、結合文字・絵文字のBackspace、256文字の上限、貼り付けを確認する。
- [ ] **マウス**：ホイールで3行ずつ動く。ヘルプ内の移動は本文の位置に影響しない。終了・中断後、マウスでの文字選択が通常の端末の動作に戻る。
- [ ] **コード**：Rustのコードに色が付き、未知の言語でも内容はそのまま表示される。色なしでは色が出ない。
- [ ] **表**：広い画面では左寄せ・右寄せ・中央揃えの罫線付きの表になり、狭い画面では全セルを縦形式で読める。セルを検索した後にリサイズしても、同じ箇所の付近に留まる。

### 数式の画像表示

- [ ] **画像になるもの**：Kitty/Ghosttyで表示モードがKITTYになり、分数・根号・総和・積分・ギリシャ文字・`pmatrix`（丸括弧）・`bmatrix`（角括弧）・`aligned`が画像になる。未知のコマンドを含む式だけが、TeXと理由の表示に戻る。
- [ ] **スクロールと再描画**：数式の途中が画面の上端・下端にかかる状態にし、`j`/`k`の連打、検索でのジャンプ、ヘルプの開閉、リサイズ、`Ctrl+z`/`fg`を試す。残像・重複・ステータス行へのはみ出しがなく、画像の途中の行位置が保たれる。
- [ ] **テキストへの切替と終了**：plain/off、非対応の端末、tmuxの自動設定の失敗時、screen内、背景色が取得できないときに、TeXとして読める。画像の生成中に`q`を押すとすぐ終了し、画像・raw mode・カーソル・マウスが元に戻る。

### tmux

Unicodeプレースホルダーに対応した端末上で、RGB色を保持する設定のtmuxを使います。

- [ ] **自動設定**：パススルーを手動で設定せずに起動し、対象のペインだけが`allow-passthrough all`になって数式画像が見える。plain/offや数式のない文書では設定が変わらない。
- [ ] **画面操作**：画像の上下の切り抜き、ヘルプ、検索、ペインの分割・移動・ズーム・リサイズ、ウィンドウの切替と復帰を試し、ステータス行や別のペインに残像が出ない。
- [ ] **非アクティブ時のリサイズ**：別のペインにフォーカスしたままサイズを変えた後でも、画像が元に戻る。
- [ ] **同時起動**：fumiを2つ同時に開き、片方を終了してももう片方の画像が消えない。

### 記録の分け方

- [ ] 同じ条件での初回と再実行、SSH経由での直接転送、Linuxは、それぞれ別に記録する。MVP時点の手動確認を、v1の合格として流用しない。
