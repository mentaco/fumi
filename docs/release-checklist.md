## 様子を見るもの

- tmuxを模擬するPTY検証がCIで断続的に失敗する。2026-11-09のmacos-latestでは、自動設定と応答待ちの上限超えと、固定の待ちによる失敗が続いた。上限の分離の検出を実時間によらないRustのテストへ移し、PTY検証はやり直しと表示待ちへ変えた（[記録](v2-verification.md#ciでのtmux自動設定の上限超え2026-11-09)）。それ以外の原因で再発したら、診断の出力から調べる。`c0d9dc0`のCIは2回とも成功したが、自動設定の上限超えは今も起きており、やり直しで吸収している。`fdb67d9`のCIでは上限超えのやり直しは起きなかった。
- macOSのCIで`tests/pty_smoke.py`が約81分止まり、取り消した。検証の後始末が端末の出力を読まずに待つと止まることを手元で再現して修正し、CIに20分の上限を設けた。修正後のCIは`fdb67d9`までの3回とも成功した。ただし回数が少なく、CIの原因とは断定できず、停止のきっかけも未特定（[記録](v2-verification.md#macosのciでのpty検証の停止)）。
- リサイズ中の画像のちらつきは当面許容（仕様12.2節）。同期更新の導入後に減ったかは未確認。
- 通常の文書の移動p95が、`36492fb`の19 msから22 msへ増えた。目標内で、原因は未調査。

## 確認済み（2026-11-09）

- Rust 1.88.0（`rust-version`）で`cargo test --all-targets --all-features`が成功（macOS arm64、GitHub Actionsの両OS）。
- GitHub Actionsのmacos-latestでtmux 3.8の実tmux検証6グループが成功（実行42597985671）。
- 大きな画像は、合成した2,500万画素の画像でも0.6秒以内に表示され、最大メモリは約240 MiB以下（Apple M3）。2秒のタイムアウトは起きなかった。
