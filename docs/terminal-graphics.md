# 数式・端末ガイド

## 数式の表示条件

ブロック数式はRaTeX 0.1.15と同梱KaTeXフォントでPNGを生成し、Kitty Graphics Protocolで転送します。端末名だけでは有効化せず、プロトコル応答、セルのピクセル寸法、背景色を確認します。生成中や失敗時はTeXソースを表示し、文書の閲覧を続けられます。

`--graphics auto`と`--graphics kitty`の両方で照会応答が必要です。数式画像化の対象がない文書では照会を省略します。`--plain` / `--graphics off`は能力照会・画像転送を行いません。screen内はテキスト表示です。

| 制限 | 値 |
|---|---|
| 式のソース | 最大16 KiB |
| 同時生成 | 最大2子プロセス |
| 生成時間 | 1式2秒 |
| 表示の高さ | 最大12セル行 |
| キャッシュ | PNGとデコード相当量の合計128 MiB |
| 起動時の自動設定・能力照会 | 合計150 ms以内の待ち時間 |

分数、根号、総和、積分、ギリシャ文字、添字・上付き、行列、alignedを確認しています。`matrix`は括弧なし、`pmatrix`は丸括弧、`bmatrix`は角括弧です。完全なKaTeX/LaTeX互換は保証しません。未知コマンドや外部ファイル参照・実行・マクロ定義関連は、その式をTeX表示へ戻します。

`--color never`では数式自体を白黒にします。インライン数式とMarkdown画像はテキスト表示です。数式画像の生成に追加のランタイムや外部TeXは必要ありません。

## tmux

外側の端末がKittyのUnicodeプレースホルダーに対応し、tmuxがRGB色を保持できる必要があります。初回起動と中断からの復帰では、mdviewのペインをアクティブにしてください。

画像化対象のある文書を開くと、`TMUX_PANE`で指定されたペインに対し、`tmux`コマンドで`allow-passthrough all`を自動設定します。設定ファイルへの追記は不要です。他ペイン、グローバル設定、`.tmux.conf`は変更しません。**自動設定した値はmdview終了後もそのペインに残ります。** `--plain` / `--graphics off`、数式画像化対象のない文書では自動設定しません。

画像の転送にはDCSパススルー、配置には通常の本文セルと同じUnicodeプレースホルダーを使います。数式は最大297列へ縮小します。初回照会後の転送応答は抑止し、リサイズ時はtmuxから寸法と色を取得します。`--color never`でも、画像IDを伝えるセルのRGB制御は使います。

自動設定の失敗、無応答、仮想配置エラー、寸法・背景色の取得失敗ではTeX表示へ戻します。入れ子のtmux、異なる端末への再接続、複数クライアントへの同時描画は対応対象外です。Kitty画像対応でもUnicodeプレースホルダーに未対応の端末では表示できません。照会後のエラーや、未対応の配置命令を黙って無視する端末を確実に検知できるとは限りません。

## 表示に問題がある場合

まず`mdview --plain file.md`または`mdview --graphics off file.md`で本文を確認してください。報告にはOS、端末・tmuxのバージョン、フォント、画面サイズ、再現する最小のMarkdownを含めます。手順は[開発・貢献ガイド](../CONTRIBUTING.md#不具合報告)を参照してください。

端末ごとの検証は[v1検証記録](v1-verification.md)に記録しています。PTYの応答エミュレータによる転送確認と、GUI端末上での画像の目視確認は区別します。追加環境では[実端末チェックリスト](manual-testing.md)を使ってください。
