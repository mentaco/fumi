# 利用ガイド

ビルドとインストールは[README](../README.md#ビルドと起動)を参照してください。

## CLI

```text
fumi [OPTIONS] <FILE>

      --plain                 能力照会・画像転送・拡大文字を無効化
      --color <MODE>          auto / always / never（既定: auto）
      --graphics <MODE>       auto / off / kitty（既定: auto）
  -h, --help                  使い方を表示して終了
  -V, --version               バージョンを表示して終了
```

`FILE`は一つだけ指定します。拡張子による制限はなく、相対パスは起動時の作業ディレクトリから解決します。ハイフンで始まる名前には`fumi -- -memo.md`、名前が`-`の実ファイルには`fumi ./-`を使います。`fumi -`は未対応の標準入力としてエラーになります。

UTF-8の通常ファイルを最大32 MiBまで読みます。先頭のBOMは除去し、CRLFはLFに正規化します。不正UTF-8、ディレクトリ、FIFO、デバイスファイルは拒否します。通常ファイルを指すシンボリックリンクは利用できます。空ファイルは`(empty)`と表示します。

stdinとstdoutの両方にTTYが必要で、`TERM`の未設定・空・`dumb`はエラーです。`--plain`や`--color always`もこの条件を変更しません。`--help`と`--version`はTTYなしで利用できます。

## 移動と表示位置

移動は折り返し後の表示行を単位とします。キー一覧は[README](../README.md#使い方)と画面内の`?`で確認できます。位置は先頭0%・末尾100%で、画面に収まる文書は100%です。リサイズ後はソース位置を基準に閲覧位置を保ちます。

端末は20列×4行以上が必要です。これより小さくするとサイズ不足の表示になり、移動を止めます。広げると本文へ戻り、サイズ不足中も終了できます。

ヘルプは独立してスクロールできます。`q` / Esc / `?`で本文へ戻り、本文の位置を保ちます。`g`を一度押した待ち状態でのEscは待ちだけを取り消します。

## 検索

`/`で検索入力を開き、Enterで確定します。大文字小文字を区別するリテラル検索で、正規表現は使いません。最大256書記素で、日本語と貼り付けに対応します。折り返しをまたぐ一致も検索し、`n` / `N`で末尾・先頭を循環します。

| 検索入力中の操作 | 動作 |
|---|---|
| Enter | 確定。空入力なら前回の検索語を再利用 |
| Esc / `Ctrl+c` | 検索語・一致・閲覧位置を検索開始前の状態へ戻す |
| Backspace | 末尾の1書記素を削除 |
| `Ctrl+u` | 入力を全消去 |
| `q` | 検索文字として入力 |

数式はTeXソース全体が検索対象です。例えば`q`は`\qquad`にも一致します。空セル等の補完ラベルは検索対象に含めません。

## 色と数式

`--color auto`は空でない`NO_COLOR`を尊重します。`always` / `never`の明示指定が優先します。色なしでも太字・下線・反転を使い、見出しと検索結果を区別します。`--plain`でも色は使用でき、色も消すには`--plain --color never`を指定します。

`--graphics kitty`も能力照会を必要とします。画像が出ない場合の条件とtmuxの動作は[数式・端末ガイド](terminal-graphics.md)を参照してください。

## 終了コード

| コード | 意味 |
|---|---|
| `0` | 正常終了、ヘルプ・バージョン表示 |
| `1` | ファイル、TTY、端末初期化等のエラー |
| `2` | 引数不足、未知のオプション、未対応の`-`等 |
| `130` | `Ctrl+c` / SIGINTによる終了 |
| `143` | SIGTERMによる終了 |

`Ctrl+z`で中断し、シェルの`fg`で復帰できます。通常終了・割り込み・中断では端末状態の復旧を試みます。文書は起動時に一度だけ読み、終了時にも本文をファイルや標準出力へ書き出しません。
