# 利用ガイド

インストール方法は[README](../README.md#インストール)を参照してください。

## コマンドライン

```text
fumi [OPTIONS] <FILE>

      --plain                 能力照会・画像転送・拡大文字を無効化
      --color <MODE>          auto / always / never（既定: auto）
      --graphics <MODE>       auto / off / kitty（既定: auto）
  -h, --help                  使い方を表示して終了
  -V, --version               バージョンを表示して終了
```

### 開けるファイル

- 一度に開けるファイルは1つです。拡張子は問いません。
- 相対パスは、fumiを起動したディレクトリから解決します。
- UTF-8の通常ファイルを最大32 MiBまで読みます。先頭のBOMは取り除き、改行コードのCRLFはLFにそろえます。
- 通常ファイルへのシンボリックリンクも開けます。
- 空のファイルは`(empty)`と表示します。
- 次のものは開けません：不正なUTF-8、ディレクトリ、FIFO、デバイスファイル、標準入力（`fumi -`）。

ファイル名が`-`で始まる場合は、次のように指定します。

```sh
fumi -- -memo.md   # ハイフンで始まる名前
fumi ./-           # 名前がちょうど「-」のファイル
```

### 端末の条件

- 標準入力と標準出力の両方が端末（TTY）である必要があります。パイプやリダイレクトでは起動しません。
- 環境変数`TERM`が未設定・空・`dumb`の場合はエラーになります。
- `--plain`や`--color always`を付けても、上の条件は変わりません。
- `--help`と`--version`は端末でなくても使えます。

## 移動と表示位置

キー一覧は[README](../README.md#キー操作)か、画面内で`?`を押すと確認できます。

- 移動は「折り返した後の表示行」が単位です。
- ステータスの位置表示は、先頭が0%、末尾が100%です。1画面に収まる文書は常に100%です。
- ウィンドウサイズを変えても、読んでいた箇所を保ちます。
- 端末は20列×4行以上が必要です。これより小さいとサイズ不足の表示になり、移動できません（終了はできます）。広げると元の画面に戻ります。

ヘルプ画面は本文とは別にスクロールできます。Esc / `?`で閉じると、本文は開く前の位置のままです。`q`はヘルプ表示中もツールを終了します。

`gg`の`g`を1回押した直後にEscを押すと、`g`の入力だけを取り消します（終了はしません）。

## 検索

`/`で検索欄を開き、Enterで確定します。

- 大文字・小文字を区別する、文字列そのままの検索です。正規表現は使えません。
- 最大256文字（書記素単位）まで入力できます。日本語入力や貼り付けにも対応しています。
- 折り返しをまたぐ一致も見つけます。
- `n` / `N`で次・前の一致へ移動します。末尾まで行くと先頭に戻ります（逆方向も同様）。
- 検索確定後のEscで検索を終了し、検索語・ハイライト・件数表示を解除します。本文の位置は変わりません。解除後は、新しい検索語を入力するまで`n` / `N`や空入力のEnterは何もしません。Escでツールが終了することはありません。

| 検索入力中のキー | 動作 |
|---|---|
| Enter | 確定。何も入力していなければ前回の検索語で検索 |
| Esc / `Ctrl+c` | 取消。検索語・一致・表示位置を検索前の状態に戻す |
| Backspace | 末尾の1文字を削除 |
| `Ctrl+u` | 入力をすべて消去 |
| `q` | 文字の「q」として入力（終了しない） |

数式はTeXのソース全体が検索対象です。たとえば`q`で検索すると`\qquad`にも一致します。一方、空のセルなどにfumiが補って表示するラベル（`(列1)`など）は検索対象外です。

## 色と数式

- `--color auto`（既定）は、環境変数`NO_COLOR`が空でなければ色を使いません。`--color always` / `never`を明示した場合はそちらが優先されます。
- 色がなくても、太字・下線・反転で見出しや検索結果を区別できます。
- `--plain`でも色は使えます。色も消したい場合は`--plain --color never`とします。
- `--graphics kitty`を指定しても、端末への能力照会は行います（照会に応答しない端末では画像になりません）。

数式が画像にならない場合や、tmuxでの動作は[数式・端末ガイド](terminal-graphics.md)を参照してください。

## 中断と終了

- `Ctrl+z`で一時中断し、シェルの`fg`で再開できます。
- 通常の終了、`Ctrl+c`などの割り込み、中断のいずれでも、端末の状態を元に戻そうとします。
- 文書は起動時に一度だけ読み込みます。終了時にファイルや標準出力へ本文を書き出すことはありません。

| 終了コード | 意味 |
|---|---|
| `0` | 正常終了、ヘルプ・バージョンの表示 |
| `1` | ファイル・TTY・端末初期化などのエラー |
| `2` | 引数の不足、未知のオプション、未対応の`-`など |
| `130` | `Ctrl+c`（SIGINT）による終了 |
| `143` | SIGTERMによる終了 |
